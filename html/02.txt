Es un comentario HTML. Puede colocarse en cualquier sección del documento y su única función es servir como anotación para los desarrolladores. No posee atributos y su uso es totalmente opcional.

2.b)
<div id="bloque1">Contenido del bloque1</div>
<div> es un elemento que sirve como contenedor estructural para aplicar estilos o manipulación mediante scripts. Este contiene el atributo id tiene como valor "bloque1" el cual sirve para distinguirlo de otros <div>, generalmente dentro de un archivo css.

3.b)
<img src="" alt="lugar imagen" id="im1" name="im1" width="32" height="32" longdesc="detalles.htm" />
La etiqueta <img> se utiliza para mostrar una imagen. Dentro de esta hay diferentes atributos. "src" se utiliza para definir la ruta donde está alojada la imagen. "alt" se usa para describir textualmente la imagen en caso de que no cargue. "name" es un identificador utilizado generalmente por servidores a diferencia de "id" que es utilizado por hojas de estilos. "width" y "height" definen las dimensiones de la imagen. Finalmente el atributo "longdesc" proporciona un descripcion detallada de la imagen (obsoleto en versiones modernas)

4.b)
<meta name="keywords" lang="es" content="casa, compra, venta, alquiler"/>
<meta http-equiv="expires" content="16-Sep-2019 7:49 PM"/>
Estas dos etiquetas se colocan exclusivamente dentro de la sección <head>. El Primer <meta> proporciona palabras clave a los motores de búsqueda (actualmente ignorado por la mayoría) y el atributo lang indica que el contenido del atributo está en español.
El segundo <meta> tiene el atributo "http-expires". Este le indica al navegador que el documento caduca en una determinada fecha y hora.

2.e) 
<a href="http://www.e-style.com.ar/resumen.html" type="text/html" hreflang="es" charset="utf-8" rel="help">Resumen HTML</a>
La etiqueta <a> define un hipervínculo que al hacer clic en el texto "Resumen HTML", navega a la URL especificada. Los atributos adicionales describen el tipo MIME, el idioma y la codificación.

2.f)
<table width="200" summary="Datos correspondientes al ejercicio vencido">
<caption align="top"> Título </caption>
<tr>
<th scope="col">&nbsp;</th>
<th scope="col">A</th>
<th scope="col">B</th>
<th scope="col">C</th>
</tr>
<tr>
<th scope="row">1o</th>
<td>&nbsp;</td>
<td>&nbsp;</td>
<td>&nbsp;</td>
</tr>
<tr>
<th scope="row">2o</th>
<td>&nbsp;</td>
<td>&nbsp;</td>
<td>&nbsp;</td>
</tr>
</table>
Todas estas etiquetas definen una tabla que tiene de 200 píxeles de ancho. Tiene un título ("Título") y 3 columnas (A, B, C) y 3 filas (encabezados + dos filas de datos). Las celdas vacías utilizan "&nbsp;" (espacio de no separación) para que el navegador muestre los bordes. Los atributos scope asocian los encabezados con sus columnas/filas.
